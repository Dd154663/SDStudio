개인정보처리방침

시행일: 2026년 10월 5일

1. 개요

SDStudio(이하 「앱」)는 NovelAI 이미지 생성을 위한 오픈소스 데스크톱(Windows·macOS·Linux) 및 Android 앱입니다. 앱의 개발자는 사용자 데이터를 수집하거나 보관하는 서버를 운영하지 않습니다. 앱이 다루는 모든 데이터는 사용자의 기기에 저장되며, 사용자가 직접 실행한 기능에 필요한 경우에만 아래에 명시한 외부 서비스로 전송됩니다.

2. 앱이 처리하는 데이터와 저장 위치

앱은 다음 데이터를 사용자의 기기 안에만 저장합니다.

  • 프로젝트, 씬, 프롬프트, 프리셋, 템플릿 등 사용자가 작성한 작업 데이터
  • 생성하거나 불러온 이미지
  • 앱 환경설정
  • 사용자가 직접 입력한 NovelAI API 토큰

이 데이터는 개발자에게 전송되지 않습니다. 사용자는 앱의 데이터 폴더를 삭제하거나 앱을 제거하여 언제든지 기기에 저장된 데이터를 지울 수 있습니다.

환경설정 내보내기에서 사용자가 「NovelAI 토큰 파일도 함께 내보내기」를 직접 켠 경우에만 NovelAI API 토큰이 별도 파일로 기기의 다운로드 폴더에 저장됩니다. 이 파일의 토큰은 암호화되지 않으며, 파일을 가진 사람은 사용자의 NovelAI 계정으로 이미지를 생성할 수 있습니다. 이 파일은 안전하게 보관하고 다른 사람과 공유하지 마세요. 앱은 토큰 파일을 Google 드라이브에 올리지 않습니다.

3. NovelAI로의 전송

사용자가 이미지 생성 등 NovelAI 기능을 실행하면, 그 요청을 처리하는 데 필요한 프롬프트, 생성 설정, 이미지, NovelAI API 토큰이 NovelAI(https://novelai.net)로 직접 전송됩니다. 이 전송은 사용자의 기기와 NovelAI 사이에서만 이루어지며 개발자의 서버를 거치지 않습니다. NovelAI로 전송된 데이터는 NovelAI의 개인정보처리방침에 따라 처리됩니다. SDStudio는 NovelAI와 무관한 독립 오픈소스 프로젝트입니다.

4. Google 드라이브 연동

이 절은 사용자가 앱(데스크톱·Android)에서 Google 드라이브 연동 기능을 사용하기 위해 Google 계정을 연결한 경우에만 적용됩니다.

  • 요청 권한 범위: 앱은 https://www.googleapis.com/auth/drive.file 범위 하나만 요청합니다. 이 범위로 앱은 앱이 직접 만든 파일과 폴더(Google 드라이브 안의 SDStudio 폴더와 그 안의 백업 파일)에만 접근할 수 있으며, 사용자의 다른 드라이브 파일은 보거나 읽거나 수정할 수 없습니다.
  • 읽는 계정 정보: 앱은 연결 상태를 표시하기 위해 Google 계정의 이메일 주소와 드라이브 저장 용량 정보만 읽습니다. 그 밖의 Google 계정 정보는 읽지 않습니다.
  • 사용 방식: 자동 동기화는 없습니다. 백업 파일(프로젝트, 프리셋, 템플릿, 환경설정)을 드라이브에 올리거나 드라이브에서 받는 작업은 사용자가 앱에서 직접 실행할 때에만 이루어집니다.
  • 파일 삭제: 앱에서 드라이브의 파일을 삭제하면 그 파일은 영구 삭제되지 않고 Google 드라이브 휴지통으로 이동합니다.
  • 토큰 보관: 데스크톱 앱은 Google 인증 토큰을 운영체제가 제공하는 보안 저장 기능으로 암호화하여 기기에만 저장합니다. Android 앱에서는 Google Play 서비스가 인증을 관리하며, 앱은 Google 인증 토큰을 따로 영구 저장하지 않습니다.
  • 연결 해제: 앱에서 연결을 해제하면 앱은 Google 인증 토큰을 폐기합니다. 또한 사용자는 언제든지 Google 계정 권한 페이지에서 앱의 접근 권한을 철회할 수 있습니다.
  • 전송 대상: Google 드라이브와 주고받는 데이터는 사용자의 기기와 Google 사이에서만 오가며, 개발자나 다른 제3자의 서버로 전송되지 않습니다.
  • Google Play 서비스가 없는 Android 기기: 이 경우 앱은 Google 계정을 연결하지 않으며, 백업 파일은 Android 공유 기능으로 사용자가 고른 앱에 넘겨집니다. 이후 처리는 사용자가 고른 앱의 방침을 따릅니다.

SDStudio가 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 행위는 Limited Use(제한적 사용) 요건을 포함한 Google API 서비스 사용자 데이터 정책(Google API Services User Data Policy)을 준수합니다. 앱은 Google 사용자 데이터를 사용자에게 보이는 기능(백업 파일 올리기·받기와 연결 상태 표시)을 제공하는 목적으로만 사용하며, 광고에 사용하거나 판매하지 않고, 사람이 열람하지 않습니다.

5. 제3자 제공·판매·광고·분석 없음

앱은 어떠한 사용자 데이터도 개발자나 제3자에게 제공하거나 판매하지 않으며, 광고 목적으로 사용하지 않습니다. 앱에는 사용 분석, 추적, 광고 도구가 포함되어 있지 않습니다.

6. 아동의 개인정보

앱은 만 13세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

7. 방침의 변경

이 방침이 변경되면 이 페이지를 갱신하고 상단의 시행일을 새 날짜로 바꾸어 알립니다.

8. 문의

이 방침이나 앱의 데이터 처리에 관한 문의는 아래 창구를 이용해 주세요.

Privacy Policy

Effective date: October 5, 2026

1. Overview

SDStudio (the “App”) is an open-source desktop (Windows, macOS, Linux) and Android app for creating images with NovelAI. The developer does not operate any server that collects or stores user data. All data handled by the App is stored on your device, and it is sent to the external services described below only when a feature you start requires it.

2. Data the App Handles and Where It Is Stored

The App stores the following data only on your device:

  • Your work data, such as projects, scenes, prompts, presets, and templates
  • Images you generate or import
  • App settings
  • The NovelAI API token you enter

None of this data is sent to the developer. You can delete the data stored on your device at any time by deleting the App’s data folder or uninstalling the App.

Only if you turn on “Also export NovelAI token file” in the settings export does the App save your NovelAI API token as a separate file in your device’s Downloads folder. The token in this file is not encrypted, and anyone who has the file can generate images with your NovelAI account. Keep this file safe and do not share it. The App never uploads the token file to Google Drive.

3. Data Sent to NovelAI

When you use a NovelAI feature, such as generating an image, the prompts, generation settings, images, and NovelAI API token needed for that request are sent directly to NovelAI (https://novelai.net). This transfer takes place only between your device and NovelAI and does not pass through any developer server. Data sent to NovelAI is handled under NovelAI’s Privacy Policy. SDStudio is an independent open-source project and is not affiliated with NovelAI.

4. Google Drive Integration

This section applies only if you connect your Google account in the App (desktop or Android) to use the Google Drive integration.

  • Requested scope: The App requests only the https://www.googleapis.com/auth/drive.file scope. With this scope, the App can access only the files and folders it creates (the SDStudio folder in your Google Drive and the backup files inside it). It cannot see, read, or modify any other files in your Drive.
  • Account information read: To show the connection status, the App reads only your Google account email address and your Drive storage quota. It does not read any other Google account information.
  • How it is used: There is no automatic sync. Backup files (projects, presets, templates, and settings) are uploaded to or downloaded from Drive only when you start the action yourself in the App.
  • File deletion: When you delete a Drive file from the App, the file is moved to your Google Drive trash rather than permanently deleted.
  • Token storage: On desktop, the App encrypts your Google authorization token with the operating system’s secure storage and keeps it only on your device. On Android, authorization is managed by Google Play services, and the App does not persistently store your Google authorization token.
  • Disconnecting: When you disconnect in the App, the App revokes and discards the Google authorization token. You can also revoke the App’s access at any time on your Google Account permissions page.
  • Where data goes: Data exchanged with Google Drive travels only between your device and Google. It is never sent to the developer or to any other third-party server.
  • Android devices without Google Play services: On these devices the App does not connect a Google account. Instead, backup files are handed to an app you choose through the Android share sheet, and that app’s own policy applies from then on.

SDStudio’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. The App uses Google user data only to provide user-facing features (uploading and downloading backup files and showing the connection status). It does not use this data for advertising, does not sell it, and no person reads it.

5. No Sharing, Selling, Advertising, or Analytics

The App does not share or sell any user data to the developer or to any third party, and does not use it for advertising. The App contains no analytics, tracking, or advertising tools.

6. Children’s Privacy

The App is not directed to children under the age of 13, and it does not knowingly collect personal information from children.

7. Changes to This Policy

If this policy changes, this page will be updated and the effective date shown at the top will be changed accordingly.

8. Contact

For questions about this policy or how the App handles data, please use the channels below.
