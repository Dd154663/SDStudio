SDStudio

NovelAI 이미지 생성을 위한 데스크톱·Android 오픈소스 작업 도구입니다.

다운로드 소스 코드 (GitHub)

English summary

주요 기능

  • 프롬프트·프리셋·씬 관리

    프롬프트와 생성 설정을 프리셋으로 저장하고, 씬 단위로 나누어 체계적으로 관리합니다.

  • 대량 생성

    여러 씬을 한꺼번에 대기열에 올려 원하는 만큼 이미지를 연속으로 생성합니다.

  • 캐릭터 프리셋·템플릿

    자주 쓰는 캐릭터 설정과 프로젝트 템플릿을 저장해 새 작업에 바로 불러옵니다.

  • 데스크톱 + Android

    Windows·macOS·Linux 데스크톱 앱과 Android 앱을 함께 제공합니다.

  • 백업 내보내기·불러오기

    프로젝트·프리셋·환경설정을 파일로 내보내고 다른 기기에서 불러올 수 있습니다.

  • Google 드라이브 연동 예정

    백업 파일을 사용자가 직접 Google 드라이브에 올리고 받을 수 있게 할 예정입니다. 자동 동기화는 하지 않습니다.

데이터 보관

SDStudio에는 개발자가 운영하는 서버가 없습니다. 프로젝트, 이미지, 프리셋, 설정은 모두 사용자 기기에 저장됩니다. NovelAI API 토큰은 사용자가 직접 입력하며 기기에만 저장되고 NovelAI로만 전송됩니다. 자세한 내용은 개인정보처리방침을 참고해 주세요.

SDStudio는 NovelAI와 무관한 독립 오픈소스 프로젝트입니다. NovelAI는 해당 권리자의 상표이며, SDStudio는 NovelAI의 공식 제품이 아닙니다.

English summary

SDStudio is an open-source desktop (Windows, macOS, Linux) and Android app for creating images with NovelAI.

  • Organize prompts, presets, and scenes.
  • Generate images in bulk from a queue of scenes.
  • Save character presets and project templates for reuse.
  • Export and import backups of projects, presets, and settings.
  • Google Drive integration (planned): manually upload and download your backup files. No automatic sync.

There is no developer-operated server. All projects, images, presets, and settings stay on your device. Your NovelAI API token is stored only on your device and is sent only to NovelAI.
